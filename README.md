# MetaSearch

Before Metacritic added its current advanced searching, its search was very basic, which made me crazy.

.NET Core & MVC app which can be set to scrape metacritic for movie data, store it in a Firebase database and present it on a website with advanced search options for:
- Rating
- Year
- Genre

Allows account creation to star want-to-watch movies and mark as seen.

Stores cast and crew data which can be seen in an expanded view, as well as a link to the metacritic page for the movie.
